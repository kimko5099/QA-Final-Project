# QA Final Project

## Project Overview
This project demonstrates manual QA testing of web, mobile, and API functionality. It includes test case design, test execution, bug reporting, and documentation of actual and expected results.

## Testing Performed
- Web application testing
- Mobile application testing
- API testing
- Functional testing
- Positive and negative testing
- Boundary value testing
- Equivalence partitioning
- Bug reporting

## Tools Used
- Jira
- Postman
- Android Studio
- Chrome
- Opera
- Microsoft Excel

## Project Files
**QA_Final_Project_Test_Cases.xlsx** contains:
- Web test cases
- Mobile test cases
- API test cases
- Expected and actual results
- Pass/Fail results
- Jira bug report references

## Skills Demonstrated
Manual Testing | Test Case Design | Bug Reporting | API Testing | Mobile Testing | Web Testing | Jira | Postman
